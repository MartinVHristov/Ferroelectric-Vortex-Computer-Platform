\begin{abstract}
This document is the complete engineering specification for a graphics processor built on ferroelectric vortex memory cells, using a fixed neural network as the pixel shader.

Instead of programmable shader cores that execute sequential instructions, the device computes pixel colors using a fixed neural network implemented as a series of matrix-vector multiplications on a crossbar array. The neural network has 10 layers of 1024$\times$1024 matrices. Each layer is a single parallel operation.

The baseline device provides:

\begin{itemize}
    \item \textbf{Internal pixel rate:} 196 Gp/s
    \item \textbf{External pixel rate:} 176.4 Gp/s
    \item \textbf{MAC throughput:} $2.06 \times 10^{18}$ MAC/s
    \item \textbf{Power:} 560 mW
    \item \textbf{Efficiency:} 350 Gp/J
    \item \textbf{Die area:} 71 mm$^2$
    \item \textbf{Cost:} \$9.11
\end{itemize}

The device uses standard 28 nm CMOS with hafnium zirconium oxide (Hf$_{0.5}$Zr$_{0.5}$O$_2$, HZO) atomic layer deposition. No exotic materials are required. The complete fabrication flow has 18 steps and 10 masks.

The document covers architecture, cell geometry and materials, fabrication flow, circuit design, operating principles, performance specifications, verification and qualification, failure modes and mitigations, packaging, and an advanced optimization configuration available separately.

The design is released openly. No patent is sought.

\textbf{This is a 6DUFT inspired technology.}
\end{abstract}

\part{Introduction and Overview}
%=====================================================================

\section{Purpose and Scope}

This document is the complete engineering specification for a graphics processor built on ferroelectric vortex memory cells, using a fixed neural network as the pixel shader.

It provides every parameter, process step, circuit specification, and procedure required to build, test, and operate the baseline device.

The document is written for:

\begin{itemize}
    \item Foundry process engineers who will fabricate the device.
    \item Circuit designers who will integrate the device.
    \item Test engineers who will qualify the device.
    \item System engineers who will deploy the device.
\end{itemize}

No prior knowledge of any theoretical framework is required. All necessary engineering information is contained in this document.

\section{What the Device Is}

The device is a graphics processor that computes pixel colors using a neural network implemented as a series of matrix-vector multiplications.

Each neural shader layer is a 1024$\times$1024 crossbar of ferroelectric cells. The crossbar stores the neural network weights. Input pixel attributes are applied as voltages on dual word lines. Output pixel values are read from the bit lines.

The neural network has 10 layers. Each layer is a single parallel operation. The output of each layer passes through an on-chip analog rectifier (the activation function) before entering the next layer.

The device accepts compressed scene data over a PCIe 5.0 interface and outputs compressed frames over the same interface. On-chip decompression and encoding reduce the external data bandwidth by a fixed factor.

\section{Why a Neural Shader}

Traditional GPUs use programmable shader cores that execute sequential instructions for each pixel. This requires instruction fetch and decode, register file access, arithmetic operations, memory access, and control flow. Each of these steps consumes power and takes time.

A neural shader replaces the sequential shader program with a fixed neural network. The neural network is a series of matrix-vector multiplications. The crossbar performs each multiplication in a single parallel operation.

The result is a pixel shading pipeline reduced to 10 matrix-vector multiplications, each taking picoseconds.

\section{What the Device Is Not}

The device is not:

\begin{itemize}
    \item A traditional GPU. It does not execute programmable shader code.
    \item A ray tracing accelerator. It cannot perform ray tracing.
    \item A general-purpose compute device. It is specialized for neural network-based graphics rendering.
    \item Field-programmable. The neural network weights are fixed at fabrication.
    \item A training device. The neural network is trained offline and the weights are programmed at fabrication.
\end{itemize}

\section{Key Advantages}

\begin{itemize}
    \item \textbf{External pixel rate:} 176.4 Gp/s, which is 70.6$\times$ a typical flagship GPU's display output.
    \item \textbf{Very low power:} 560 mW total, which is 804$\times$ lower than a typical flagship GPU.
    \item \textbf{High efficiency:} 350 Gp/J, which is 350$\times$ a typical flagship GPU.
    \item \textbf{Small die area:} 71 mm$^2$, which is 8.6$\times$ smaller than a typical flagship GPU.
    \item \textbf{Low cost:} \$9.11 per chip.
    \item \textbf{Non-volatile weights:} No memory initialization required. Instant boot.
    \item \textbf{CMOS compatible:} Standard 28 nm CMOS with HZO atomic layer deposition.
    \item \textbf{No exotic materials.}
\end{itemize}

\section{Key Limitations}

\begin{itemize}
    \item \textbf{Baseline internal pixel rate:} 196 Gp/s, which is 0.44$\times$ a flagship GPU.
    \item \textbf{No programmability:} The neural network weights are fixed at fabrication.
    \item \textbf{No ray tracing:} The neural shader cannot perform ray tracing.
    \item \textbf{Low weight precision:} 1-bit weights at the baseline configuration.
\end{itemize}

\section{Device Positioning}

The baseline device is positioned for:

\begin{itemize}
    \item Embedded graphics
    \item Low-power desktop and mobile systems
    \item Applications where the neural shader has been trained for the target rendering style
    \item Multi-display systems where the high external pixel rate is beneficial
\end{itemize}

An advanced optimization configuration with higher internal pixel rate, lower power, and higher efficiency is available separately and is described at the end of this document.

\section{Neural Network Structure}

The neural shader is a 10-layer fully-connected neural network with 1024 inputs and 1024 outputs per layer.

\begin{center}
\begin{tabular}{p{3cm}p{3cm}p{5cm}}
\toprule
\textbf{Layer} & \textbf{Size} & \textbf{Function} \\
\midrule
Input & 64 attributes & Pixel attributes (differential) \\
1 & 1024 $\times$ 1024 & Feature extraction \\
2 & 1024 $\times$ 1024 & Feature processing \\
3 & 1024 $\times$ 1024 & Feature processing \\
4 & 1024 $\times$ 1024 & Feature processing \\
5 & 1024 $\times$ 1024 & Feature processing \\
6 & 1024 $\times$ 1024 & Feature processing \\
7 & 1024 $\times$ 1024 & Feature processing \\
8 & 1024 $\times$ 1024 & Feature processing \\
9 & 1024 $\times$ 1024 & Feature processing \\
10 & 1024 $\times$ 1024 & Output \\
\bottomrule
\end{tabular}
\end{center}

Each layer is a matrix-vector multiplication. The input to each layer is the output of the previous layer after the on-chip analog rectifier. The output layer produces 1024 values, of which 4 are used for RGBA color output.

The weights are fixed at fabrication and are supplied to the foundry as a mask pattern. See Section "Weight Data Interface" for the exact data format.

\section{Dual Word Line Architecture}

The signed weights are represented using dual word lines:

\begin{itemize}
    \item \textbf{WL$^+$:} Carries the positive input $+x_i$.
    \item \textbf{WL$^-$:} Carries the negative input $-x_i$.
\end{itemize}

Cells with a positive weight connect to WL$^+$. Cells with a negative weight connect to WL$^-$. The current on bit line $j$ is the sum over all inputs, giving the correct signed matrix-vector product.

\section{Internal and External Pixel Rates}

\subsection{Internal Pixel Rate}

The internal pixel rate is the rate at which the device processes pixels through the neural shader.

\begin{equation}
\text{Pixel rate}_{\rm internal} = \frac{N_{\rm active}}{t_{\rm compute}}
\end{equation}

where $N_{\rm active}$ is the number of simultaneously active neural networks and $t_{\rm compute}$ is the compute time per layer.

At the baseline configuration: $N_{\rm active} = 14$, $t_{\rm compute} = 71.4$ ps, giving $196$ Gp/s.

\subsection{External Pixel Rate}

The external pixel rate is the rate at which rendered frames are transferred to the host over the PCIe 5.0 interface.

At the baseline configuration: $176.4$ Gp/s.

\subsection{MAC Throughput}

\begin{equation}
\text{MAC rate} = \text{Pixel rate} \times 10 \times 1024 \times 1024
\end{equation}

At the baseline configuration:

\begin{equation}
\text{MAC rate} = 196 \times 10^9 \times 10{,}485{,}760 = 2.06 \times 10^{18}\ \text{MAC/s}
\end{equation}

\section{Pipeline Architecture}

At any instant, all 10 layers are active, each processing a different pixel. A pixel exits layer 10 after 10 compute cycles.

\begin{center}
\begin{tabular}{p{5cm}p{4cm}}

\textbf{Parameter} & \textbf{Value} \\
\midrule

Layer compute time & 71.4 ps (baseline) \\
Pixel exit time & $10 \times 71.4\ \text{ps} = 714\ \text{ps}$ \\
Active networks & 14 (baseline) \\
\bottomrule
\end{tabular}
\end{center}

\section{Weight Data Interface}

The neural network weights are supplied to the foundry as a binary mask pattern file. The file format is as follows:

\begin{center}
\begin{tabular}{p{4cm}p{4cm}p{5cm}}
\toprule
\textbf{Field} & \textbf{Size} & \textbf{Description} \\
\midrule
Header & 64 bytes & Magic number, version, layer count \\
Layer 1 weights & $1024 \times 1024$ bits & Row-major order, 1 bit per cell \\
Layer 2 weights & $1024 \times 1024$ bits & Row-major order \\
$\vdots$ & $\vdots$ & $\vdots$ \\
Layer 10 weights & $1024 \times 1024$ bits & Row-major order \\
Trailer & 16 bytes & Checksum \\
\bottomrule
\end{tabular}
\end{center}

A bit value of 1 indicates a conductive cell. A bit value of 0 indicates an insulating cell. The file is used directly to generate mask M5 (disk pattern).

The total weight data size is $10 \times 1024 \times 1024$ bits = 1.31 MB.

\section{Clock Domains}

The device uses two clock domains:

\begin{center}
\begin{tabular}{p{4cm}p{3cm}p{5cm}}
\toprule
\textbf{Domain} & \textbf{Frequency} & \textbf{Used by} \\
\midrule
PCIe / logic & 500 MHz & Decompressor, encoder, control logic \\
Compute & Layer compute rate (14.0 GHz baseline) & Neural shader crossbar, drivers, comparator \\
\bottomrule
\end{tabular}
\end{center}

The two clock domains are synchronized through a standard asynchronous FIFO at the boundary between the decompressor output and the neural shader input, and at the boundary between the neural shader output and the encoder input.

\section{Neural Network Weights}

The neural shader weights are fixed at fabrication. They are determined offline and supplied to the foundry as a mask pattern file. The file format is given in Section "Weight Data Interface."

The weights are 1-bit at the baseline configuration. They are encoded as the presence or absence of a conductive region in each ferroelectric cell.

\subsection{Programming Time}

With 100 cells programmed in parallel:

\begin{equation}
t_{\rm program} = \frac{10{,}485{,}760 \times 22.2\ \text{ns}}{100} = 2.33\ \text{ms}
\end{equation}

\section{Compute Operation}

\subsection{Procedure}

\begin{enumerate}
    \item Pre-charge bit lines to 0 V (16.6 ps).
    \item Apply differential input voltages to dual word lines.
    \item Bit lines charge through cell conductances.
    \item Sample-and-hold captures bit line voltage (1 ps).
    \item Analog rectifier converts the output.
    \item Buffer chain drives the next layer's word lines.
\end{enumerate}

\subsection{Compute Time}

\begin{equation}
t_{\rm compute} = \max(t_{\rm pre}, t_{\rm WL} + t_{\rm settle} + t_{\rm charge}, t_{\rm comp})
\end{equation}

At the baseline configuration:

\begin{equation}
t_{\rm compute} = \max(16.6, 3.45, 71.4) = 71.4\ \text{ps}
\end{equation}

The comparator time dominates.

\subsection{Pixel Rate}

\begin{equation}
\text{Pixel rate} = \frac{N_{\rm active}}{t_{\rm compute}} = \frac{14}{71.4 \times 10^{-12}} = 196\ \text{Gp/s}
\end{equation}

\section{External Interface}

\subsection{Input}

Compressed scene data is received over PCIe 5.0 at 64 GB/s. The scene graph decompressor expands the data into pixel attributes.

\subsection{Output}

Rendered frames are compressed by the frame encoder and transmitted over PCIe 5.0 at 64 GB/s.

\subsection{External Pixel Rate}

\begin{equation}
\text{Pixel rate}_{\rm external} = 176.4\ \text{Gp/s}
\end{equation}

\begin{enumerate}

    \item Wait for power-on reset (1 $\mu$s).
    \item Load calibration from on-chip memory.
    \item Begin operation.
\end{enumerate}

\section{Power-Down Sequence}

\begin{enumerate}
    \item Complete pending operations.
    \item Remove logic supply.
\end{enumerate}

The neural network weights are non-volatile. Power-off is instant. No state loss.

\section{Error Handling}

\subsection{Correctable Errors}

Correct the error using ECC, log the event, and continue operation.

\subsection{Uncorrectable Errors}

Retry the operation. If retry fails, mark the affected region as degraded.

\section{Overview}

The verification plan follows the three-gate structure:

\begin{enumerate}
    \item \textbf{Gate 1:} The ferroelectric phase is confirmed immediately after annealing.
    \item \textbf{Gate 2:} The cell switches correctly at the single-cell level.
    \item \textbf{Gate 3:} The device works at scale in an array.
\end{enumerate}

\section{Gate 1: Ferroelectric Phase Confirmation}

\subsection{When to Measure}

After Step 10 (RTA Annealing).

\subsection{What to Measure}

A P-V hysteresis loop on a TiN/HZO/TiN capacitor.

\subsection{Test Structure}

A 50 $\mu$m $\times$ 50 $\mu$m capacitor fabricated on the same wafer, in the scribe line or a dedicated test area.

\subsection{Equipment}

Radiant Precision LC ferroelectric tester, or equivalent.

\subsection{Procedure}

\begin{enumerate}
    \item Contact the top and bottom electrodes with probe tips.
    \item Apply a voltage sweep from $-5$ V to $+5$ V and back.
    \item Measure the polarization as a function of voltage.
    \item Plot the P-V loop.
\end{enumerate}
