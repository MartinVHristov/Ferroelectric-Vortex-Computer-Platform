\begin{abstract}
This document is the complete engineering specification for a non-volatile memory device based on ferroelectric vortex cells.

Each cell stores information in the topological winding number of a ferroelectric vortex pinned at a central TiN pillar. The vortex core is conductive, enabling resistance-based readout. The device provides non-volatile storage with low read latency, very low write energy, and very low power consumption.

The baseline device provides:

\begin{itemize}
    \item \textbf{Density:} 1.95 GB/cm$^2$
    \item \textbf{Capacity:} 1.95 GB on a 100 mm$^2$ die
    \item \textbf{Read latency:} 3.80 ns
    \item \textbf{Write latency:} 21.1 ns
    \item \textbf{Write energy:} 595 fJ per bit
    \item \textbf{Endurance:} $2.74 \times 10^{10}$ cycles
    \item \textbf{Retention:} $>$10 years at 85$^\circ$C
    \item \textbf{Power:} 97.2 mW on a 100 mm$^2$ die
    \item \textbf{Die cost:} \$5.36
    \item \textbf{Chip cost:} \$7.36
    \item \textbf{Cost per GB:} \$2.75 (die-cost basis)
\end{itemize}

The device uses standard 28 nm CMOS with hafnium zirconium oxide (Hf$_{0.5}$Zr$_{0.5}$O$_2$, HZO) atomic layer deposition. No exotic materials are required. The complete fabrication flow has 18 steps and 10 masks.

The document covers cell architecture, material specifications, the complete fabrication flow, circuit design, operating principles, performance specifications, verification and qualification, failure modes and mitigations, packaging, and an advanced optimization configuration available separately.

The design is released openly. No patent is sought.

\textbf{This is a 6DUFT inspired technology.}
\end{abstract}

\section{Purpose and Scope}

This document is the complete engineering specification for a non-volatile memory device based on ferroelectric vortex cells.

It provides every parameter, process step, circuit specification, and procedure required to build, test, and operate the baseline device.

The document is written for:

\begin{itemize}
    \item Foundry process engineers who will fabricate the device.
    \item Circuit designers who will integrate the device.
    \item Test engineers who will qualify the device.
    \item System engineers who will deploy the device.
\end{itemize}

No prior knowledge of any theoretical framework is required. All necessary engineering information is contained in this document.

\section{What the Device Is}

The device is a non-volatile memory that stores information in the topological winding number of a ferroelectric vortex.

Each memory cell consists of:

\begin{itemize}
    \item A ferroelectric nanodisk made of hafnium zirconium oxide (HZO).
    \item A central TiN pinning pillar.
    \item A bottom electrode (TiN).
    \item A top electrode (TiN).
    \item A select transistor (FinFET).
\end{itemize}

The polarization field in the ferroelectric disk forms a vortex around the pinning pillar. The vortex has an integer winding number $n$ that describes how many times the polarization rotates around the pillar.

The vortex core is a narrow region where the polarization is suppressed. The core is conductive because the polarization suppression creates a deep potential well with high carrier density.

The winding number determines the core geometry, which determines the electrical resistance between the top and bottom electrodes. Reading the resistance reveals the stored winding number.

For binary operation:

\begin{itemize}
    \item $n=0$: uniform polarization, no vortex, resistance $>10^{12}\ \Omega$.
    \item $n=1$: single vortex, resistance in the k$\Omega$ range.
\end{itemize}

The ON/OFF ratio exceeds $10^9$, making binary discrimination straightforward.

\section{What the Device Is Not}

The device is not:

\begin{itemize}
    \item A DRAM replacement. DRAM has higher endurance ($10^{16}$ cycles vs.\ $2.74 \times 10^{10}$ cycles). This device is for applications where non-volatility, low power, and high density matter more than unlimited endurance.

    \item A NAND replacement at the baseline tier. NAND has lower cost per bit at the baseline tier. The device becomes cheaper than NAND at the advanced optimization configuration.

    \item A compute device. The device is a storage device. It does not perform matrix-vector multiplication.

    \item A general-purpose memory. The write-verify procedure adds latency to writes. The device is optimized for read-heavy workloads.
\end{itemize}

\section{Key Advantages}

\begin{itemize}
    \item \textbf{Non-volatile:} Data is retained without power. 10+ year retention at 85$^\circ$C.

    \item \textbf{High density:} 1.95 GB/cm$^2$ at the baseline tier, which is 15.6$\times$ denser than DRAM.

    \item \textbf{Fast read:} 3.80 ns read latency, which is 13,158$\times$ faster than NAND flash.

    \item \textbf{Low write energy:} 595 fJ per bit, which is 16.8$\times$ lower than DRAM.

    \item \textbf{Very low power:} 97.2 mW for a 100 mm$^2$ die, which is 31--51$\times$ lower than DRAM.

    \item \textbf{CMOS compatible:} Standard 28 nm CMOS with HZO atomic layer deposition. No exotic materials.
\end{itemize}

\section{Key Limitations}

\begin{itemize}
    \item \textbf{Lower endurance than DRAM:} $2.74 \times 10^{10}$ cycles vs.\ $10^{16}$ cycles. Wear leveling is required for write-intensive applications.

    \item \textbf{Write-verify required:} The write operation requires a verify step to ensure reliable switching, increasing the write latency.

    \item \textbf{Baseline cost:} The baseline cost per GB is higher than NAND flash. The cost advantage appears at the advanced optimization configuration.
\end{itemize}

\section{Device Positioning}

The baseline device is positioned for:

\begin{itemize}
    \item Embedded memory
    \item Low-volume production
    \item Educational and research use
    \item Applications where the HZO process is already established
\end{itemize}

An advanced optimization configuration with higher density, lower write energy, and lower cost per GB is available separately and is described at the end of this document.

\section{Annular Area}

The annular area for $n=1$ is:

\begin{equation}
A_1 = \pi[(r_{\rm pillar} + r_{\rm core})^2 - r_{\rm pillar}^2]
\end{equation}

where $r_{\rm core}$ is the vortex core radius. With $r_{\rm pillar} = 10$ nm and a vortex core radius of 2.31 nm:

\begin{equation}
A_1 = \pi[(10\ \text{nm} + 2.31\ \text{nm})^2 - (10\ \text{nm})^2] = 161.9\ \text{nm}^2
\end{equation}

\section{Comparator}

\subsection{Circuit Description}

The comparator discriminates between the two resistance states by comparing the cell current to a reference current.

\begin{center}
\begin{tabular}{|c|}
\hline
\textbf{Comparator Topology} \\
\hline
Input current $\to$ Current mirror $\to$ Integration node $\to$ Latch $\to$ Output \\
\hline
\end{tabular}
\end{center}

The current-mirror input stage converts the input current to a voltage on the integration node. The regenerative latch then amplifies the voltage difference to a full-swing digital output.

\subsection{Auto-Zeroing}

The comparator offset is cancelled by auto-zeroing:

\begin{enumerate}
    \item Phase 1: Input shorted, measure offset, store on capacitor.
    \item Phase 2: Input connected, measure signal, subtract offset.
\end{enumerate}

Auto-zeroing adds approximately 1 ns to the read time but eliminates offset errors. It is scheduled during idle cycles and does not impact the read latency.

\section{Write Operation}

\subsection{Write Procedure}

For each cell:

\begin{enumerate}
    \item Decode bank address (1 ns).
    \item Decode row address (0.5 ns).
    \item Activate word line (0.1 ns).
    \item Apply write voltage attempt 1 (10 ns).
    \item Verify (read back, 2 ns).
    \item If failed, apply attempt 2 (10 ns).
    \item Verify (2 ns).
    \item If failed, apply attempt 3 (10 ns).
    \item Verify (2 ns).
    \item If failed, apply attempt 4 (10 ns).
    \item Verify (2 ns).
\end{enumerate}

\section{Periodic Recalibration}

Reference cells (1\% of the array) are programmed to known states during initial calibration.

Recalibration procedure:

\begin{enumerate}
    \item Read all reference cells.
    \item Compare to stored values.
    \item Update comparator thresholds.
    \item Update write voltage lookup table.
\end{enumerate}

Frequency: Hourly during normal operation. Time: 1 ms (background operation).

\section{Power-On Sequence}

\begin{enumerate}
    \item Apply 1 V logic supply.
    \item Wait for power-on reset (1 $\mu$s).
    \item Apply write voltage supply (from charge pump).
    \item Load calibration data from non-volatile memory.
    \item Begin normal operation.
\end{enumerate}

Total boot time: $<$10 $\mu$s.

\section{Power-Down Sequence}

\begin{enumerate}
    \item Complete pending operations.
    \item Remove write voltage supply.
    \item Remove logic supply.
\end{enumerate}

Data is non-volatile. Power-off is instant. No data loss.

\section{Error Handling}

\subsection{Correctable Errors}

\begin{enumerate}
    \item Correct the error using ECC.
    \item Log the event.
    \item Continue operation.
\end{enumerate}

\subsection{Uncorrectable Errors}

\begin{enumerate}
    \item Retry the operation.
    \item If retry fails, mark block as bad.
    \item Use a spare block.
    \item If no spares remain, report to host.
\end{enumerate}

\section{Wake-Up Procedure}

Production test performs the wake-up:

\begin{enumerate}
    \item Apply $10^4$ write cycles to all cells.
    \item Measure resistance after wake-up.
    \item Store calibration values.
    \item Begin normal operation.
\end{enumerate}

Wake-up time: $10^4 \times 21.1\ \text{ns} = 211\ \mu\text{s}$.

\section{Overview}

The verification plan is designed to catch problems at the earliest possible stage, minimizing wasted effort and fabrication runs.

The plan follows the three-gate structure:

\begin{enumerate}
    \item \textbf{Gate 1:} The ferroelectric phase is confirmed immediately after annealing.
    \item \textbf{Gate 2:} The vortex cell switches correctly at the single-cell level.
    \item \textbf{Gate 3:} The device works at scale in an array.
\end{enumerate}

\section{Gate 1: Ferroelectric Phase Confirmation}

\subsection{When to Measure}

After Step 10 (RTA Annealing), before any further patterning.

\subsection{What to Measure}

A P-V hysteresis loop on a simple TiN/HZO/TiN capacitor.

\subsection{Test Structure}

A 50 $\mu$m $\times$ 50 $\mu$m capacitor fabricated on the same wafer, in the scribe line or a dedicated test area.

\subsection{Equipment}

Radiant Precision LC ferroelectric tester, or equivalent.

\subsection{Procedure}

\begin{enumerate}
    \item Contact the top and bottom electrodes with probe tips.
    \item Apply a voltage sweep from $-5$ V to $+5$ V and back.
    \item Measure the polarization as a function of voltage.
    \item Plot the P-V loop.
\end{enumerate}
