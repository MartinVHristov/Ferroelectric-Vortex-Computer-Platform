Abstract

This document is the public engineering specification for the Vortex FeRAM, a non-volatile memory built from ferroelectric vortex cells. It contains the complete information required to fabricate, test, package, and operate the device. It does not contain derivations, references to external technical papers, or information about how the design's numerical values were determined. Every value is stated as a specification, a standard calculation with specified inputs, a measured material property, or a target pending first-silicon characterization.

The product. A single-tier non-volatile memory built on standard 28 nm CMOS with a ferroelectric hafnium–zirconium oxide (HZO) back-end. The Vortex FeRAM is designed for embedded, industrial, and automotive applications where non-volatility and high cycle endurance matter, and where fast read latency improves system performance.

Positioning. The Vortex FeRAM is designed for applications that benefit from non-volatility, very high cycle endurance, and read latency 6–9× faster than DDR5 system-to-system. It is not a DDR5 replacement: its write throughput is 0.7 GB/s (write-verify-limited), which is NAND-class, not DDR5-class. Status of the numerical values. Every value in this specification is a design target. Part I — Product Overview

I.1 What the Memory Is

The Vortex FeRAM is a non-volatile memory based on ferroelectric vortex cells. Each cell consists of:

  • A ferroelectric nanodisk made of hafnium–zirconium oxide (HZO).
  • A central TiN pinning pillar whose height equals the ferroelectric film thickness minus the cap recess.
  • A self-aligned Al₂O₃ dielectric cap in a recess at the pillar top (7 nm).
  • A bottom electrode (TiN) and a top electrode (TiN).
  • A select transistor (5-fin FinFET, Ron = 0.9 kΩ).

The polarization in the ferroelectric disk forms a vortex around the central pillar. The vortex has an integer winding number n. The core of the vortex (a narrow annulus around the pillar) is conductive; the outer ferroelectric region is insulating; the pillar-top region is covered by the Al₂O₃ dielectric cap and blocked for DC. Reading the resistance between the top and bottom electrodes reveals the stored winding number.

For binary operation:

  • n = 0 (uniform polarization, no vortex): resistance above 10¹² Ω.
  • n = 1 (single vortex): resistance in the kΩ range.
  • ON/OFF ratio: above 10⁵.

The Vortex FeRAM is binary (1 bit per cell).

I.3 Functional Overview

I.3.1 The memory cell

Each cell is a ferroelectric disk with a central TiN pillar, a self-aligned Al₂O₃ dielectric cap in a recess at the pillar top, and TiN top and bottom electrodes. The pillar height equals the ferroelectric film thickness minus the cap recess. The read current flows radially through the conductive vortex core annulus. The outer ferroelectric region (between the core boundary and the disk edge) is insulating and contributes only capacitance. The pillar-top region is pure dielectric (no ferroelectric) and blocks DC current through the cap.

I.3.2 The read path

The read path is a current-mode latch comparator with auto-zeroing. The cell current and a reference current are compared at the input pair; the latch amplifies the difference. The comparator offset is canceled by auto-zeroing every 1,000 accesses. The word line is held at the read voltage (9.88 mV nominal, tunable from 8.5 to 14.0 mV) during a read burst. The reference trip current is 0.165 μA nominal; the on-state cell current is 1.127 μA at the nominal read voltage.

I.3.3 The write path

The write path uses a four-level write-verify ladder: 2.223, 2.445, 2.668, 2.890 V. Each level corresponds to a write field of 1.50, 1.65, 1.80, 1.95 MV/cm across the 14.82 nm HZO film. After each pulse, the word is verified. The write-verify ladder completes when all cells have switched, or after four attempts. The average per-word write latency is 45.2 ns; the maximum is 49.5 ns.

The write-verify operates on a full 64-bit word at a time. Each pulse is applied to the entire word. The write energy per cell is 0.88 fJ (nominal, 25 °C).

I.3.4 The hierarchical word-line architecture

The memory uses hierarchical word lines. Each 1024-cell main word line is split into two sub-word-lines (SWLs) of 512 cells each, center-fed. The main word line enable is driven from a global row decoder that serves a group of 8 sub-arrays, then amplified by a local row decoder at each sub-array. The V_WL boost rail (1.5 V) compensates for the SWL IR drop.

One data word is 64 binary cells. A burst accesses the selected SWL groups to deliver 16 words (BL16).

I.5 What the Product Is and Is Not

I.5.1 What it is

  • A general-purpose non-volatile memory with resistance-based readout.
  • A storage-class memory for applications where non-volatility, low power, and high read speed matter.
  • A CMOS-compatible device fabricated on 28 nm CMOS (LELE) with ferroelectric HZO atomic layer deposition.
  • A binary (1 bit per cell) production design.
  • A high-endurance product, with 2.45 × 10⁹ cycles at 1% fail (24,500× the endurance of NAND SLC).

I.5.2 What it is not

  • A DDR5 write-bandwidth replacement. The write-verify architecture fundamentally limits write throughput to 0.7 GB/s (NAND-class), not 51.2 GB/s (DDR5-class). Read throughput is DDR5-class (51.2 GB/s).
  • A DRAM endurance replacement. The endurance (2.45 × 10⁹ cycles) is 4 × 10⁶× below DRAM's 10¹⁶ cycles. Applications needing DRAM-class endurance should use DRAM.
  • A compute device. This is storage only.
  • A drop-in replacement for existing memory interfaces. The device has its own custom DDR-style interface specification (Part IX).
  • A power-efficiency tier at 50%+ duty (it loses to DDR5 on power per GB at 50% duty and above).

I.6 Positioning

The Vortex FeRAM is designed for applications where at least one of the following is a primary requirement:

  • Non-volatility with fast read latency. Data survives power-off, and read latency is 6–9× faster than DDR5 system-to-system.
  • High cycle endurance. 2.45 × 10⁹ cycles at 1% fail (24,500× NAND SLC, but 4 × 10⁶× below DRAM).
  • Embedded, industrial, or automotive applications where non-volatility and read latency matter more than write throughput or power density.

The Vortex FeRAM is not designed for:

  • Write-heavy workloads where throughput matters more than latency (use DDR5 or NAND).
  • Applications where DRAM-class endurance is required.
  • Applications where 100% duty cycle sustained operation without a thermal pad is required.

Part II — Material System

II.1 The Ferroelectric Material

The memory uses hafnium–zirconium oxide (Hf₀.₅Zr₀.₅O₂, HZO) as the ferroelectric material. HZO is a CMOS-compatible ferroelectric that forms the orthorhombic ferroelectric phase after a 450 °C rapid thermal anneal. It is deposited by atomic layer deposition (ALD) from metal-chloride precursors and water.

II.10 Moisture Sensitivity

HZO absorbs moisture from air. The film must be annealed within 1 hour of deposition. Storage between deposition and anneal must be in a nitrogen-purged environment with H₂O below 1 ppm. Transfer between tools must be in vacuum or N₂-purged cassette. Failure to observe this constraint degrades the ferroelectric phase fraction and reduces device yield.

III.2 The Three Cell Regions

The cell has three distinct regions between the top and bottom electrodes:

  1. Annular region (from pillar edge to pillar edge + core radius): the conductive vortex core annulus. Capacitance C_ann, resistance R_ann.
  2. Outer ferroelectric region (from core boundary to disk edge): ferroelectric, insulating. Capacitance C_outer in parallel with C_ann. No DC conduction.
  3. Pillar-top region (above the pillar, under the cap): pure dielectric (no ferroelectric because the pillar top is recessed by the cap thickness). Capacitance C_above (from the Al₂O₃ cap), DC path blocked.

The total capacitance is C_total = C_ann + C_outer + C_above.

III.4 Read Behavior

Reading a cell is a resistance measurement between the top and bottom electrodes. The cell current is set by the annular path through the vortex core:

  • At n=1 (vortex present), the annular path is conductive: 1.127 μA at V_read = 9.88 mV.
  • At n=0 (uniform polarization, no vortex), the annular path is insulating. Off-state current is ~10 fA, which is 10⁴× below the trip point.
  • The Al₂O₃ dielectric cap over the pillar-top region blocks DC current through the pillar, so the pillar-top region does not contribute to either the on-state or off-state current (only capacitance).

Reference architecture. The reference trip point (0.165 μA) is set at approximately 15% of the on-state signal (1.127 μA). The off-state leakage floor is far below the trip point (10 fA vs 0.165 μA). This gives a large positive differential for the on-state (0.962 μA), enabling fast comparator decisions (0.354 ns at the SS corner).

The inhibit voltage applied to unselected cells during a write to an adjacent cell is 0.95 V. III.7 The Wake-Up Procedure

HZO films require a wake-up cycle before reaching their full remanent polarization. The wake-up is performed once at production test:

  1. Apply 10⁴ write-verify cycles to every cell.
  2. Measure the cell resistance at the post-wake-up state.
  3. Store the calibration values in on-die OTP.
  4. Mark the cell as "woken up" for the rest of its operating life.

Wake-up time per cell: 10⁴ × 21.2 ns = 212 μs. After wake-up, the remanent polarization increases by 1.5–2× (a measured material property of HZO). The post-wake-up P_s is the value stated in this document (13.07 μC/cm²); the pre-wake-up P_s is lower and is not used for device operation.

Production test cost. The wake-up cycle adds ~30 seconds to the per-die production test time (parallel wake-up across all cells). This is included in the packaged test cost in Part XIII.

Part IV — Fabrication Flow

IV.1 Process Overview

The memory is fabricated on a standard 28 nm CMOS line with ferroelectric HZO atomic layer deposition capability. The product flow has 21 numbered steps. Each step is one process module (lithography, etch, deposition, implant, anneal, or CMP); cleans, metrology, and inspections are not counted separately.

The front-end CMOS (5-fin FinFET transistors, high-k gate dielectric, CoSi₂ source/drain) is standard 28 nm technology with one process deviation: CoSi₂ source/drain (stable to 700 °C) instead of the standard NiSi (stable only to 400 °C). The ferroelectric back-end (HZO deposition, pillar-hole damascene, self-aligned cap, patterning) uses standard ALD, CMP, and RIE tools.

Key flow characteristics. The flow is damascene: the ferroelectric is deposited first, then a hole is cut for the pillar, then the pillar is filled and planarized flush with the ferroelectric. There is no Al₂O₃ etch stop under the ferroelectric (the pillar-hole etch stops directly on the bottom TiN electrode via in-situ optical emission spectroscopy). The cap over the pillar is self-aligned: the pillar is etched back by 7 nm, the recess is filled with Al₂O₃, and a CMP planarizes the surface flush with the ferroelectric top. This eliminates both the DC-blocking etch stop and the misalignment risk of a lithographically patterned cap.

Part V — Circuit Design

V.1 Circuit Overview

The circuit architecture is built around the current-mode read path and the four-level write-verify ladder.

Key circuit subsystems:

  • Read path: current-mode latch comparator with auto-zeroing, reference current generator, and read-voltage trim DAC.
  • Write path: four-level H-bridge write driver, inhibit driver, and charge pump.
  • Hierarchical word-line architecture: global row decoder, local row decoder, and sub-word-line (SWL) drivers.
  • Reference: 60 kΩ resistor-based current reference, trim range ±30%.
  • ECC: SECDED (72/64), internal, transparent to host.
  • Power management: four power states (P0 active, P1 reduced clock, P2 clock-gated, P3 deep sleep).
  • Clock generation: charge-pump PLL, 100 MHz to 1 GHz.
  • Temperature sensing: 4 on-die sensors, max-of-4 + 3 °C margin reporting.

V.2 The Read Comparator

V.2.1 Circuit description

The comparator discriminates between the two resistance states by comparing the cell current to a reference current. It is a current-mode latch with four stages:

  1. Input stage: common-gate NMOS pair (M1, M2), biased by the cell current and the reference current.
  2. Current mirror: PMOS mirror (M3, M4) loads the input pair.
  3. Latch: cross-coupled inverter pair (M5–M8) regenerates the output.
  4. Output buffer: standard inverter (M9, M10).

The current-mode latch has no integration capacitor. The cell current and the reference current are compared directly at the input pair; the latch amplifies the difference. With the dielectric cap over the pillar, the cell current is the annular current only; the pillar-top shunt is blocked, so the comparator sees the full state-discriminating signal.

V.2.4 Auto-zeroing

The comparator offset is canceled by auto-zeroing:

  1. Offset sampling: the input pair is shorted (both inputs at the reference current). The offset is stored on a 100 fF capacitor at the latch input.
  2. Read: the input pair is connected to the cell. The stored offset is subtracted from the signal.

Auto-zeroing is performed every 1,000 accesses. The offset drift over 1,000 accesses is negligible. The auto-zeroing is done in the background (no access stalls). The overhead is 5 ps every 1,000 accesses, about 0.0001% of the 4.71 ns serial read latency.

Part VI — Operating Principles

VI.1 Overview

The Vortex FeRAM supports three fundamental operations: write, read, and erase. Write and erase use the four-level write-verify ladder with opposite polarities. Read uses the current-mode latch comparator with the reference current at 0.165 μA. All operations use the hierarchical word-line architecture (512-cell sub-word-lines, center-fed).

VI.2 Write Operation

VI.2.1 Write procedure

For each 64-bit data word:

  1. Decode bank address (1.0 ns).
  2. Decode sub-array, row, and word address (0.5 ns).
  3. Activate main word line and target sub-word-line driver (0.1 ns).
  4. Apply write voltage attempt 1 (10 ns pulse).
  5. Verify (read back, 2 ns).
  6. If any cell in the word failed, apply attempt 2 (10 ns).
  7. Verify (2 ns).
  8. If any cell failed, apply attempt 3 (10 ns).
  9. Verify (2 ns).
  10. If any cell failed, apply attempt 4 (10 ns).
  11. Verify (2 ns).
  12. Cells that fail all four attempts are marked and repaired by ECC.

Average write time: 45.2 ns per 64-bit word. Maximum (all four attempts): 49.5 ns.

VI.2.5 Cold-corner write behavior

At 10 °C and −5% VDD, the coercive field rises to 1.531 MV/cm, and level 1 of the ladder (2.112 V at −5% VDD) gives only 1.425 MV/cm — below E_c(10 °C). Cells do not switch at level 1 at the cold corner. They need level 2 or higher.

At the cold corner, every word needs all four attempts. Cold-corner write latency is 49.5 ns (all four attempts). Cold-corner write energy is 0.94 fJ per cell.

Writes below 0 °C are outside the validated operating range. The controller must warm the device to ≥10 °C before accepting writes. Reads are functional at all storage temperatures (−40 to 125 °C).

VI.3 Read Operation

VI.3.1 Read procedure

For each 64-bit data word:

  1. Decode bank address (1.0 ns).
  2. Decode sub-array, row, and word address (0.5 ns).
  3. Activate main word line and target sub-word-line driver (0.1 ns).
  4. Apply V_read to the top electrode (9.88 mV nominal).
  5. Cell settling (0.18 ps, negligible).
  6. Comparator decision (0.178 ns TT / 0.354 ns SS).
  7. Data output through the output register and I/O driver (2.0 ns).

Total read latency (TT, serial first-access): 4.71 ns on-chip. Steady-state (pipelined, row already open): 2.63 ns on-chip. SS corner: 4.88 ns serial, 2.80 ns pipelined. System (add 3–5 ns controller): ~7.7–9.7 ns serial, ~5.6–7.6 ns pipelined.

VI.3.3 Read operation over 10¹² reads

The read-disturb margin is a design constant over device lifetime. At 10¹² reads, the accumulated read field exposure does not cause switching. For extended read life, the design supports 10¹² reads at 25 °C and 10¹¹ reads at 85 °C without degradation.

A secondary mechanism — imprint from repeated reads at one polarity — is under investigation. The device supports an optional SWAP command (Part IX) that inverts the polarity encoding for blocks that see asymmetric read/write patterns.

VI.4 Erase Operation

VI.4.1 Erase procedure

The erase operation writes the logical "0" state (winding number n = 0) to the cell. It uses the same write-verify ladder but with opposite polarity:

  • Write operation: top electrode driven positive relative to bottom electrode, at the four ladder voltages.
  • Erase operation: bottom electrode driven positive relative to top electrode, at the four ladder voltages.

The H-bridge reverses the polarity. No separate negative charge pump is required; the on-die positive pump output is used, and the H-bridge determines which terminal is positive.

VI.6 Periodic Recalibration

VI.6.1 Reference cell refresh

The memory uses dedicated reference cells (1,024 per bank in a separate column) programmed to known states. Two refresh mechanisms are implemented:

VI.7 Power-On and Power-Down Sequences

VI.7.1 Power-on sequence

  1. Apply VDD_CORE (1.0 V) first.
  2. Apply VDD_PLL (1.0 V) within 100 μs.
  3. Apply VDDQ (1.8 V), VDD_ANALOG (1.8 V), and VPP (2.5 V) within 1 ms.
  4. Apply VPROG (3.5 V) after VDD and VDDQ have stabilized. Wait for the charge pump soft-start and the output to reach its target (~50 μs).
  5. Apply V_WL (1.5 V) last.
  6. Wait for power-on reset (1 μs).
  7. Load calibration data from on-die ROM.
  8. Release reset.
  9. Begin normal operation.

Total boot time: ~55 μs (VPROG charge pump is the dominant delay). First write command is available after the boot delay.

VI.7.2 Power-down sequence

  1. Complete pending operations.
  2. Disable V_WL.
  3. Disable the charge pump.
  4. Remove VPROG.
  5. Remove VPP.
  6. Remove VDD_ANALOG, VDDQ.
  7. Remove VDD_PLL, VDD_CORE.

The data is non-volatile, so power-off is lossless. No data is lost on power-down.

VI.7.3 Hot-plug behavior

If VPROG is present and VDDQ is off or below 90% of nominal, standard I/O pins could see VPROG through the write driver and be damaged. The device must not be hot-plugged with VPROG live and VDDQ off. The power-on reset monitors all rails and disables VPROG output until VDD and VDDQ are both up. A hot-plug detection circuit pulls VPROG to 0 V during any rail transition where VDDQ is not within 90% of nominal.

VI.8 Error Handling

VI.8.1 Correctable errors (single-bit)

  1. ECC decodes the 72-bit word and corrects the single-bit error.
  2. The error event is logged.
  3. Operation continues without host intervention.

VI.8.2 Detectable errors (double-bit)

  1. ECC detects the double-bit error (SECDED can detect but not correct).
  2. The operation is retried from the host.
  3. If the retry succeeds, the error is logged and operation continues.
  4. If the retry fails, the block is marked as bad and the data is recovered from a redundant block.

VI.8.3 Uncorrectable errors (triple-bit or more)

  1. ECC cannot correct or reliably detect.
  2. The block is marked as bad.
  3. The host is notified (ALERT_N).
  4. Data recovery from redundant blocks or from host-side redundancy.

VI.9 The Wake-Up Procedure

All HZO films require a wake-up cycle before reaching full remanent polarization. The wake-up is performed once at production test:

  1. Apply 10⁴ write-verify cycles to all cells.
  2. Measure the post-wake-up cell resistance and record the value in on-die OTP.
  3. Update the calibration values used by the read and write paths.

Wake-up time per cell: 10⁴ × 21.2 ns = 212 μs. After wake-up, the remanent polarization increases by 1.5–2×. The post-wake-up P_s is the value stated in this document (13.07 μC/cm²).

Production test cost. The wake-up cycle adds ~30 seconds to the per-die production test time (parallel wake-up across all cells). This is included in the packaged test cost.

VI.10 Read-Disturb and Write-Disturb

VI.10.1 Read-disturb

The read field is sub-threshold for HZO. The polarization state does not switch during a read. The read-disturb margin against the vortex destroy field is 20.1× at 85 °C (worst case). The read field is well below the coercive field; no cumulative switching occurs.

VI.10.2 Write-disturb

The unselected cells on the same word line receive an inhibit voltage of 0.95 V. The net field across the unselected cell is 47.9% of E_c at 85 °C — below the 50% threshold for reliable no-disturb. The unselected cells are not disturbed during a write to an adjacent cell.

VI.14 The SWAP Command (Polarity Swap)

VI.14.1 What SWAP does

The memory cell encoding is: n=1 for "written one state," n=0 for "written zero state." If a block sees asymmetric cycling (e.g., 80% of writes are to n=1, 20% to n=0), the n=1 cells fatigue faster than the n=0 cells. Over time, this creates imprint: the n=1 cells have lower remanent polarization than the n=0 cells, degrading the read margin for the n=1 state.

The SWAP command inverts the encoding for a block: n=1 becomes "written zero state," n=0 becomes "written one state." After SWAP, the previously over-cycled n=1 cells are now written as n=0 and vice versa. This equalizes the cycling across the two polarization states.

VI.14.2 SWAP protocol

  1. Each 4 KB block has a 32-bit write counter.
  2. When the counter reaches 10⁵, the controller may issue a SWAP command to the block.
  3. The memory reads the block, inverts the polarity encoding, writes back, and resets the block's 1-bit polarity flag.
  4. The counter resets to zero.

SWAP is optional. It is recommended for workloads with asymmetric read/write patterns (e.g., write-once, read-many applications). For workloads with symmetric cycling, SWAP is not required.

SWAP storage cost (when enabled): 1 bit per 64-bit word = 1.56% storage overhead.

Ship gates. The Vortex FeRAM ships contingent on four specific measurements. If any of the four fails outside its acceptance range, production is held until resolution. The four ship gates are:

  1. Core DC conductivity (Gate 2, M1). The read mechanism requires the ferroelectric core to be conductive. If measured cell current is below 0.1× the design value, the read path is broken.
  2. Core radius (Gate 2, M1). The design value is 2.317 nm. If measured r_c exceeds 3.01 nm (30% above the design value), the annular/r_c ratio drops from 4.32 to 3.32 — still comfortable, but the design window narrows. A hard r_c ship gate of 5.0 nm (annular/r_c = 2.0) applies; beyond that the design margin is not sufficient.
  3. Dry etch-back anisotropy (process qualification). The pillar etch-back must achieve ≥ 3:1 anisotropy. Below 3:1, the pillar begins to shrink and the cell resistance rises out of spec.
  4. CMP endpoint (process qualification). The cap CMP must stop at the HZO field plane with ≤ 1.0 nm Al₂O₃ overlap over the annular region. Above 1.0 nm, the read path is partially blocked.

VII.3.3 M2 — P–E loop and loop area

Setup: 50 μm × 50 μm HZO capacitor (same as Gate 1).

Measurement: Full P–E loop at 25 °C. Extract P_s, E_c, and loop area (the closed-loop area in J/m³).

Pass criterion: P_s within 10% of 13.07 μC/cm²; E_c within 5% of 1.4923 MV/cm; loop area in 2.0–3.5 × (P_s · E_c).

Use: The loop area sets the per-cell switching energy. The design value of 0.88 fJ per cell assumes a loop area of 2.49 × (P_s · E_c). If the measured loop area is 3.5 × (P_s · E_c), the per-cell write energy rises to 1.24 fJ, and the write pump current spec (80 mA sustained) is re-qualified.

VII.3.4 M3 — Above-pillar leakage

Setup: Test structure with the annular path blocked (top-electrode geometry exposes only the pillar top).

Measurement: I-V at V_read = 9.88 mV.

Pass criterion: Measured current < 1 pA. The 7 nm Al₂O₃ cap blocks DC current through the pillar-top region.

If fails: Cap deposition or CMP issue. The Al₂O₃ cap is not hermetic, or the CMP under-polished leaving a thinner than 6.5 nm effective cap. Requires deposition recipe or CMP endpoint investigation.

VII.3.5 M4 — E_c vs temperature

Setup: 50 μm × 50 μm capacitors at 10, 25, 55, 85 °C.

Measurement: P–E loop at each temperature. Extract E_c(T).

Pass criterion: E_c(T) matches the linear interpolation E_c(25 °C) × [1 − (T − 25)/579.65] within 5%. The measured temperature coefficient is used to populate the write-voltage lookup table.

VII.3.6 M5 — Switching distribution

Setup: 1,000 individual cells. Pulse amplitude sweep at fixed 10 ns pulse width.

Measurement: Fraction of cells switched vs pulse amplitude. Extract the distribution width σ.

Pass criterion: Distribution width σ ≤ 0.20 (consistent with the four-level ladder in Part VI). If σ is between 0.20 and 0.25, the write path uses a wider ladder or an extra verification step. If σ > 0.25, the write path is unreliable (grain structure investigation required).

VII.3.7 M6 — Retention projection

Setup: 256 individual cells. Programmed to n=1, post-wake-up.

Measurement: Bake at 125, 150, 175, 200 °C for 24, 100, 500, 1000 hr. Measure cell resistance after each bake.

Pass criterion: Extrapolated 10-year retention at 85 °C with 2× margin (i.e., measured retention ≥ 20 years equivalent at 85 °C).

VII.3.8 M7 — Extended endurance

Setup: 64 cells per material, pre-screened to require 4 attempts (i.e., cells that fail to switch at levels 1, 2, 3).

Measurement: Apply 4-attempt cycles continuously. Measure P_s at 10⁴, 10⁵, 10⁶, 10⁷ cycles.

Pass criterion: Extrapolated endurance (1% fail) is consistent with the design spec of 2.45 × 10⁹ cycles. If endurance is measured lower than 1 × 10⁷ cycles, the endurance spec drops to the measured value (still 100× NAND SLC, still endurance-class), and the tier positioning is updated.

VIII.15 Positioning

VIII.15.1 What works well

  • Read latency: 6–9× faster than DDR5, 5,500–7,100× faster than NAND, 2.5–3.3× faster than MRAM.
  • Read bandwidth: 51.2 GB/s (DDR5-class, much faster than NAND or MRAM).
  • Write latency: Comparable to DDR5 (within 10–20%), 2,000× faster than NAND.
  • Cell write energy: 0.88 fJ, 11,364× lower than DDR5, 568× lower than NAND, 114× lower than MRAM.
  • Non-volatility: >10 years at 85 °C. Instant power-off. No refresh.
  • Idle power: 66 mW/GB, 4–6× lower than DDR5.
  • Endurance: 2.45 × 10⁹ cycles, 24,500× better than NAND SLC.
  • Cost/GB: Comparable to DDR5 ($5.54 vs $5–8 primary).

VIII.15.2 What is weak

  • Write bandwidth: 0.7 GB/s, 73× lower than DDR5. The write-verify architecture fundamentally limits write throughput. This is not a design flaw — it is an inherent property of write-verify memory.
  • Density: 1.46 GB/cm², comparable to MRAM, but much lower than NAND (23–30 GB/cm²) or DDR5 (2.7–3.5 GB/cm²). The single-layer design and 80 nm pitch limit density.
  • Endurance vs DRAM: 2.45 × 10⁹ cycles, 4 × 10⁶× lower than DRAM. Not a DRAM endurance replacement.
  • Power at 50%+ duty: 621 mW/GB, 1.7–2.5× higher than DDR5. The Vortex FeRAM is not a power-efficiency tier at sustained operation.
  • Cost vs NAND: $5.54/GB, 5–11× more expensive than NAND SLC. Not positioned as a NAND price competitor.
  • Operating temperature: Writes require ≥10 °C; below that, cold-start warm-up or extended ladder. Reads are functional across −40 to 125 °C.

VIII.15.3 Bottom line

The Vortex FeRAM is a read-fast, non-volatile, endurance-focused memory. It is positioned for applications where:

  • Non-volatility is required (data survives power-off).
  • Read latency is the dominant performance requirement.
  • Endurance of 2.45 × 10⁹ cycles is sufficient (embedded, industrial, automotive, hot-storage).
  • Write throughput of 0.7 GB/s is acceptable (write-light workloads).
  • Cost per GB comparable to DDR5 is acceptable (not chasing NAND cost).

It is not a DDR5 replacement, not a NAND replacement, and not a DRAM endurance replacement. It occupies a distinct position: read-fast, non-volatile, endurance-differentiated, NAND-class write bandwidth.

IX.6.3 Hot-plug rules

Power-on reset monitors all rails and disables VPROG output until VDD and VDDQ are both up. A hot-plug detection circuit pulls VPROG to 0 V during any rail transition where VDDQ is not within 90% of nominal. The device must not be hot-plugged with VPROG live and VDDQ off.

Part X — Health and Safety

X.1 Production Hazards

The production of the memory uses two ALD precursors that are corrosive and require inert-atmosphere handling. These are not common knowledge for a general engineering reader, so the hazards are noted here.

X.1.1 Hafnium chloride (HfCl₄)

  • White crystalline solid, sublimes at 317 °C.
  • Reacts with water to form HCl (hydrochloric acid).
  • Corrosive to skin, eyes, and the respiratory tract.
  • Handling: inert atmosphere (N₂ or Ar), dry conditions. Standard ALD precursor handling procedure.
  • Exhaust: HCl scrubber required.

X.1.2 Zirconium chloride (ZrCl₄)

  • White crystalline solid, sublimes at 331 °C.
  • Reacts with water to form HCl.
  • Corrosive, same hazards as HfCl₄.
  • Handling: same as HfCl₄.

X.1.3 The HCl byproduct

The ALD reactions produce HCl (4 moles per mole of HfO₂ or ZrO₂). The exhaust must be scrubbed with a wet scrubber or thermal abatement. Standard semiconductor fab practice.

X.1.4 CMP slurry

The CMP planarization steps (pillar planarization and cap planarization) use silica-based slurry at pH 10–11. Standard CMP slurry handling applies: eye protection, gloves, and slurry waste treatment. Silica particles are a respiratory irritant if dried and aerosolized; slurry must be kept wet until waste treatment. Standard CMP tooling includes the required safety controls.

X.1.5 Standard semiconductor hazards

Standard semiconductor fabrication hazards (silane, hydrofluoric acid, chlorine etchants, various solvents) apply throughout the flow. These are common to all CMOS fabs and are handled by the foundry's standard safety infrastructure. No additional hazards are introduced by the HZO ferroelectric process beyond the two Hf/Zr precursors and the HCl byproduct.

X.2 Post-Production Safety

The finished memory chips are standard CMOS devices with no hazardous materials exposed. HZO is a stable ceramic; no special handling is required for the finished chip. The finished chip is safe for consumer, commercial, and industrial use.

X.3 Handling of the Finished Memory

The finished memory is a BGA-324 device, handled like any other BGA memory device:

  • ESD protection: handle in an ESD-controlled environment (wrist strap, ESD mat).
  • Moisture sensitivity: MSL 3 (168 hours floor life at 30 °C, 60% RH). Bake at 125 °C for 24 hours if floor life is exceeded.
  • Reflow: standard J-STD-020 Pb-free reflow, peak 260 °C.
  • Storage: dry pack with desiccant, ≤ 40 °C, ≤ 90% RH.

X.4 Environmental Compliance

The memory is compliant with:

  • RoHS (Restriction of Hazardous Substances) — no lead, cadmium, mercury, hexavalent chromium, PBB, or PBDE.
  • REACH (Registration, Evaluation, Authorization, and Restriction of Chemicals) — no SVHC above threshold.
  • Halogen-free (per IEC 61249-2-21).

Part XII — Software Driver and Usage Guidelines

XII.1 Purpose

This Part specifies the software interface (driver API) and the operational guidelines that any host system must follow to achieve the endurance and lifetime characteristics stated in Parts I and VIII. Because the Vortex FeRAM has very high cycle endurance (2.45 × 10⁹ cycles), wear leveling is optional for most workloads, but recommended for workloads with known asymmetric patterns.

XII.2 Lifetime vs Sustained Write Rate

The Vortex FeRAM has 2.45 × 10⁹ cycles at 1% fail. For a 1.23 GB die with a typical write amplification factor of 1.0, the lifetime under continuous writing depends on the sustained write rate:

The Vortex FeRAM does not need wear leveling for most workloads. With wear leveling (DWLV, §XII.4), the effective endurance is extended by the wear-leveling factor (typically 5–10×), giving effective lifetime of 70–140 years at peak write rate.

XII.4 Wear Leveling (Optional)

XII.4.1 The algorithm

The recommended wear-leveling algorithm (when enabled) is DWLV hybrid (Dynamic Wear Leveling with Variable window), an 8-bit counter per 4 KB block:

  1. Each 4 KB block has an 8-bit cycle counter, stored in a reserved metadata area (0.3 MB for a 1.23 GB die, 0.025% of user capacity).
  2. New writes go to the block with the lowest counter.
  3. Blocks with counter ≥ 128 (2× mean) are frozen (allowed to cool).
  4. When a block's counter reaches 200, its data is migrated to a fresh block; the block is added to the spare pool.
  5. Overshoot factor: ≤ 5× (realistic).

Wear leveling is optional. The Vortex FeRAM's 2.45 × 10⁹ cycle endurance exceeds any practical workload lifetime for most applications. Wear leveling is recommended only for workloads with known asymmetric patterns or for very long deployment lifetimes.

XII.5 SWAP Command (Polarity Swap, Optional)

XII.5.1 What SWAP does

The memory cell encoding is: n=1 for "written one state," n=0 for "written zero state." If a block sees asymmetric cycling (e.g., 80% of writes are to n=1, 20% to n=0), the n=1 cells fatigue faster than the n=0 cells. Over time, this creates imprint: the n=1 cells have lower remanent polarization than the n=0 cells, degrading the read margin for the n=1 state.

The SWAP command inverts the encoding for a block: n=1 becomes "written zero state," n=0 becomes "written one state." After SWAP, the previously over-cycled n=1 cells are now written as n=0 and vice versa. This equalizes the cycling across the two polarization states.

XII.5.2 SWAP protocol

  1. Each 4 KB block has a 32-bit write counter.
  2. When the counter reaches 10⁵, the controller issues a SWAP command to the block.
  3. The memory reads the block, inverts the polarity encoding, writes back, and resets the block's 1-bit polarity flag.
  4. The counter resets to zero.

SWAP is optional. It is recommended for workloads with asymmetric read/write patterns. SWAP storage cost (when enabled): 1 bit per 64-bit word = 1.56% storage overhead.

XII.6 Address Scrambling

The memory controller must implement address scrambling to prevent hot-spot wear. Without scrambling, sequential writes hit the same physical addresses, causing concentration of wear at low addresses.

XII.7 Read-Modify-Write and Write-Combining Buffer

Partial-word writes (less than 64 bits) trigger RMW. Cost:

  • Read the 72-bit ECC-protected word: 4.71 ns (serial).
  • Modify affected bytes.
  • Recompute ECC.
  • Write back the full 72 bits: 45.2 ns (average).
  • Total RMW: ~50 ns.

The device includes a 10 KB per-bank write-combining buffer (160 KB total) that merges partial writes before commit. The buffer reduces RMW events by 80%–90% for typical workloads. The driver should flush the buffer before power-down or before any read to a partially written word.

  • Enable address scrambling at mount time (all deployments).

  • Enable DWLV wear leveling only for workloads with known asymmetric patterns or very long deployment lifetimes (optional).
  • Schedule SWAP for workloads with asymmetric cycling (optional).
  • Log ECC error rates via the status register; a rising single-bit rate indicates the block is approaching its wear limit.
  • Handle double-bit errors by retrying once before marking the block bad.

XIII.8 The Financial Case

The Vortex FeRAM is positioned for applications where non-volatility and read speed matter more than raw capacity-per-dollar. It is comparable to DDR5 on cost per GB ($5.54 vs $5–8 primary) and cheaper at volume ($3.34 vs $3.50–$4.00). It is not a NAND price competitor. The financial case rests on the value of non-volatility (no refresh power, instant power-off) and read latency (6–9× faster than DDR5), not on undercutting commodity DRAM pricing.

XIV.3 When to Choose the Advanced Product

The Advanced product is recommended for applications where:

  • Density matters more than endurance. 31.25 GB/cm² vs 1.46 GB/cm² for the Vortex FeRAM (21× higher density).
  • Cost per GB is a primary metric. $0.76/GB primary vs $5.54/GB for the Vortex FeRAM (7.3× cheaper), and $0.41/GB volume vs $3.34/GB (8× cheaper).
  • Write latency matters. 13.5 ns per word vs 45.2 ns for the Vortex FeRAM (3.3× faster).
  • Write throughput matters. 2.37 GB/s pure-write vs 0.7 GB/s for the Vortex FeRAM (3.4× faster).
  • Read-heavy storage workloads. Sequential read bandwidth is 51.2 GB/s (same as the Vortex FeRAM), but the higher density enables larger working sets per device.
  • Wear-leveled storage is the deployment model. The Advanced product's cycle endurance is sufficient for wear-leveled consumer storage, but is not intended for hot-write applications.

The Advanced product is not recommended for applications where:

  • Very high cycle endurance (≥ 10⁸ cycles) is required. Use the Vortex FeRAM (2.45 × 10⁹ cycles) or DRAM (10¹⁶ cycles).
  • Extreme cold operation below −40 °C is required (neither product is specified below −40 °C storage).

XIV.4 When to Choose the Vortex FeRAM

The Vortex FeRAM is recommended for applications where:

  • Endurance is the dominant requirement. 2.45 × 10⁹ cycles vs the Advanced product's 5.14 × 10⁵ cycles (4,800× higher).
  • Embedded, industrial, or automotive applications where write-heavy workloads, hot-storage, or high-cycle operation is expected.
  • Simple deployment. The Vortex FeRAM's endurance exceeds most workload lifetimes even at peak write rate, so no wear-leveling infrastructure is required at the host level.
  • Comparable cost to DDR5 is acceptable, and non-volatility plus read speed justify the premium over NAND.

  • Idle power: 109 mW (66 mW/GB)

  • Non-volatile: >10 years retention, instant power-off, no refresh

What the Product Is

The Vortex FeRAM is a read-fast, non-volatile, endurance-focused memory. It is positioned for applications where non-volatility, read latency, and very high cycle endurance are the dominant requirements. It is fabricated on standard 28 nm CMOS with HZO ferroelectric atomic layer deposition.

What the Product Is Not

The Vortex FeRAM is not a DDR5 write-bandwidth replacement (write bandwidth 0.7 GB/s vs DDR5's 51 GB/s). It is not a DRAM endurance replacement (2.45 × 10⁹ cycles vs DRAM's 10¹⁶). It is not a NAND price competitor ($5.54/GB vs NAND's $0.50–1.00/GB). It is not a drop-in replacement for existing memory interfaces (custom protocol, custom controller required).

The Release Gates

The Vortex FeRAM ships contingent on four specific measurements:

  1. Core DC conductivity — single-cell I-V measurement confirming that the ferroelectric core carries DC current. If not, the read path is broken and the device requires 6–12 month redesign.
  2. Core radius — single-cell measurement confirming the vortex core radius within 30% of the 2.317 nm design value.
  3. Dry etch-back anisotropy — process qualification confirming the pillar dry etch achieves ≥ 3:1 anisotropy.
  4. CMP endpoint — process qualification confirming the cap CMP stops at the HZO field with ≤ 1.0 nm Al₂O₃ overlap over the annular region.

All four gates are measurements or process qualifications, not design questions. The design is stable; the gates confirm the numbers.
